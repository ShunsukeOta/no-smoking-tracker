# 禁煙ログ | no-smoking-tracker

禁煙で取り戻した**時間・お金・吸わなかった本数**と、禁煙のマイルストーンを表示する、端末内完結型の PWA です。

## 主な機能

- 初回起動時のプロフィール登録（禁煙開始時の年齢・1日の本数・1箱20本あたりの価格・最後に吸った日時）
- 禁煙継続時間と次のマイルストーンまでの残り時間を秒単位で更新
- 節約金額（0.001円単位）、吸わなかった本数（小数点以下5桁）、取り戻した時間（秒の小数点以下2桁）を1秒ごとに推計表示
- 端末のダークモード設定に対応。画面右上のボタンで切り替え、選択を端末に保存
- 年間の節約予測、禁煙のマイルストーン
- 設定編集・端末内の記録リセット
- Service Worker によるオフライン起動、ホーム画面へのインストール
- **サーバー送信なし**。登録情報はブラウザの `localStorage` にのみ保存

## 技術スタック

Vite / React / TypeScript / Tailwind CSS / **shadcn/ui**（Button, Card, Input, Label, Badge, Progress, Separator）/ Radix UI / lucide-react / vite-plugin-pwa


```bash
npm run test
```

## Vercel にデプロイ

1. Vercel で **Add New → Project** からこの GitHub リポジトリをインポート。
2. Framework Preset は **Vite**（自動検出）、Build Command は `npm run build`、Output Directory は `dist`。
3. デプロイ後、スマートフォンのブラウザから開き、「ホーム画面に追加」でインストール可能。

環境変数、データベース、API キーは不要です。`vercel.json` に SPA のルーティング設定を含めています。

## 計算方法

```text
経過日数 = (現在時刻 - 最後に吸った日時) ÷ 86,400,000
吸わなかった本数（推計）= 経過日数 × 1日あたりの喫煙本数
節約額（推計）= 経過日数 × 1日あたりの喫煙本数 × (1箱の価格 / 20)
取り戻した時間（推計）= 経過日数 × 1日あたりの喫煙本数 × 5分
年間節約予測 = round(365 × 1日あたりの喫煙本数 × (1箱の価格 / 20))
```

時間・節約額・本数は過去の喫煙ペースが続いたと仮定した推定値です。各値は画面表示時に丸めます。小数の本数は連続的な進捗を表現するためのものです。

## 健康情報の扱い

健康面のマイルストーンは一般的な目安であり、診断・治療や個別の回復予測を行うものではありません。紙巻きタバコの研究結果を **IQOS などの加熱式タバコにも同じ時間経過で当てはまると断定しない** よう注記しています。

## データとオフライン

すべての情報は各端末の `localStorage` に保存されます。クラウド同期やアカウント登録はありません。ブラウザデータを消去すると記録は失われます。ブラウザのプライベートモードでは保存が制限される場合があります。
